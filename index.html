    怎么理解你的分数？

    工具报告的是 AI 单题练习预估。正式写作科目按 1–6 分报告，还包含句子重组等表现。工具不提供单篇作文到正式科目分的换算。

    预估范围是相邻档位的判断，未经统计校准。它适合发现反复出现的问题，不适合作为报考或达标证明。

    这是基于公开标准的提示词评阅工具。没有使用 ETS 私有评分系统，也没有通过带分语料进行模型训练或准确率校准。

    用你常用的 AI 评分

    无需 API Key，也不需要安装 Codex。支持能按照要求输出 JSON 的 AI 对话；不同模型的反馈质量会有差异。

    1. 在练习页选择“任意 AI 对话”，独立完成作文。
    2. 点击“复制评分请求”，把全文发给 DeepSeek、豆包、通义千问、Gemini、ChatGPT 或 Claude。
    3. 复制 AI 返回的完整 JSON，粘贴到练习页并点击“导入评分结果”。原文与反馈会保存在你的本地记录中。

    评分请求已包含标准摘要、题目、原稿、反馈格式和本次编号。如返回格式不符，请在同一 AI 对话要求按原请求返回完整 JSON。

    进阶：Codex / MCP 自动写回

    配置本地 MCP 或网页工具后，在练习页选择“Codex / MCP”，写完点击“提交给 Codex”，再在聊天中说“给刚才的作文评分”。当前聊天模型读取原稿并将反馈写回。提交按钮不会自动唤醒聊天。

    MCP 配置见项目 README。首次配置后须重新启动客户端。HTTP 服务与 MCP 应使用同一个数据目录。

    API 自动评分 自选服务

    每个配置独立保存 Key；切换不会覆盖另一个模型。

    支持域名根地址、/v1 或完整 /v1/chat/completions 地址；支持 OpenAI Chat Completions 兼容协议；Anthropic 原生 Messages、Gemini 原生协议需要另外适配。

    自动评分会把题目与作文发送到你设置的服务；API 按服务商规则计费。Key 仅保留在本机服务内存，不写入磁盘、源码、浏览器存储或练习档案。刷新网页后仍可用；重启本地服务后须重新填写。兼容服务若不支持 JSON mode，可取消勾选。
